# Outbound Sales Platform

Internal platform that helps the enterprise sales team run outbound to key accounts,
covering both new business and existing customers. Built from Salesforce data (enriched by ZoomInfo),
it applies MEDDPICC, maps stakeholders and drafts persona-based, multi-channel sequences, with
human approval and a full audit trail.
